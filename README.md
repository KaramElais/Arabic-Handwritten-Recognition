# Arabic Handwritten Character Recognition

## Project Overview
This project focuses on recognizing Arabic handwritten characters using Deep Learning and Convolutional Neural Networks (CNNs) with PyTorch.

The project includes:
- Data preprocessing
- Data augmentation
- CNN model training
- Validation and testing
- Evaluation metrics
- Confusion matrix analysis
- Misclassification analysis
- Final prediction demo

## Technologies
- Python
- PyTorch
- OpenCV
- NumPy
- Matplotlib
- Scikit-learn

## Project Goal
Build an accurate and explainable Arabic handwritten character recognition system suitable for academic presentation and evaluation.
